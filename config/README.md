# Student Management System - Django

A clean and simple Student Management System built with Python Django.

## Features
- Add / Edit / Delete Students
- Search Students
- Bootstrap Responsive UI
- Admin Panel

## Tech Stack
- Python, Django
- HTML, CSS, Bootstrap
- SQLite Database

## How to Run Locally
```bash
git clone https://github.com/aksharasatya/student-management-system.git
cd student-management-system
python -m venv .venv
.venv\Scripts\activate
pip install django
python manage.py migrate
python manage.py runserver
